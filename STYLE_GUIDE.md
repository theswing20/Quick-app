# Style Guide - Quick App

## Единые стандарты верстки

### Компоненты

#### Card
Используется для всех карточек в приложении:
- `Card` - базовая карточка
- `CardContent` - контент карточки (padding: p-4)
- `CardRow` - строка в карточке с опциональной границей

Варианты:
- `default` - обычная карточка
- `elevated` - карточка с тенью
- `outlined` - карточка с границей

Пример:
```tsx
<Card variant="elevated">
  <CardContent>
    <CardRow withBorder>
      <Text>Label</Text>
      <CurrencyAmount amount={100} />
    </CardRow>
  </CardContent>
</Card>
```

#### CurrencyAmount
Компонент для отображения суммы с иконкой валюты:
- `size`: "sm" | "md" | "lg" (12px, 14px, 16px иконка)
- `variant`: "default" | "bold"
- `showIcon`: boolean (по умолчанию true)

Пример:
```tsx
<CurrencyAmount amount={100} size="md" variant="bold" />
```

### Отступы

#### Горизонтальные отступы
- `px-4` - стандартный отступ для контента
- `px-6` - отступ для модальных экранов и важных секций

#### Вертикальные отступы
- `py-3` - стандартный отступ между элементами
- `py-4` - отступ для секций
- `pb-6` - отступ снизу для секций

### Радиусы скругления

- `rounded-2xl` - стандартный радиус для карточек (16px)
- `rounded-3xl` - для больших элементов (24px)
- `rounded-full` - для круглых элементов

### Цвета текста

- `text-gray-900` - основной текст
- `text-gray-700` - вторичный текст
- `text-gray-500` - третичный текст (метаданные)
- `text-gray-600` - для описаний

### Размеры текста

- `text-sm` (14px) - мелкий текст, метаданные
- `text-base` (16px) - основной текст
- `text-lg` (18px) - заголовки элементов
- `text-xl` (20px) - заголовки секций
- `text-2xl` (24px) - большие заголовки
- `text-3xl` (30px) - очень большие заголовки

### Веса шрифтов

- `font-medium` - для обычного текста
- `font-semibold` - для акцентов
- `font-bold` - для заголовков и важных значений

### Тени

Используется компонент Card с вариантом `elevated`:
- shadowColor: '#000'
- shadowOffset: { width: 0, height: 2 }
- shadowOpacity: 0.1
- shadowRadius: 4
- elevation: 3

### Иконки

- Размер иконок: 20-24px для основных, 12px для мелких
- Цвет: `THEME.light.primary` для акцентных иконок
- Цвет: `#000000` или `#9CA3AF` для обычных иконок

### Кнопки

- Высота: `h-14` (56px)
- Радиус: `rounded-2xl` (16px)
- Primary цвет для основных действий
- Белый фон с границей для вторичных действий
